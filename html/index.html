# pawnode

PawNode is a furry organization that builds and maintains furry-first services and infrastructure, with an emphasis on open-source, privacy, and security. To better achieve this goal, PawNode operates it's own hardware and network infrastructure, stores it's own data and analytics, and does not rely on third-party cloud providers.

Please note: PawNode occasionally hosts services for close friends and community members but does not currently provide public hosting services.

# privacy

PawNode uses self-hosted Umami for privacy-focused analytics, which may include anonymous page views and basic technical details such as browser, device, and approximate location. This data is never used for advertising or sold to third parties. We also participate in CrowdSec's data exchange, as described in their Central API documentation.
